# CHARGE GAP 최종 발표용 요약 (2026-11-14)

기준: 커밋 `ad022d7` 배포본. 공개 주소: [charge-gap.onrender.com](https://charge-gap.onrender.com). 수치는 배포된 API와 같은 로컬 스냅샷에서 다시 계산했습니다.

## 1. 한 줄 소개

전기차 보급과 충전 인프라의 **지역별 구성 차이**를 16개 시도 단위로 보여 주는 데이터 시각화 웹 대시보드입니다.

- 공급 측 자료만으로 계산할 수 있는 구성 지표를 전국 기준값과 비교합니다.
- 기준 시점이 다른 자료를 섞어 충전 부족률이나 수요를 추정하지 않습니다.

## 2. 핵심 성과

| 영역 | 성과 |
|---|---|
| 서비스 | 6개 페이지 웹사이트와 JSON API 14개 경로(JSON 13 + PNG 1)를 Render 무료 플랜에 배포. API를 먼저, 웹을 나중에 배포하는 순서로 운영 |
| 분석 | 16개 지역 충전 인프라 구성 격차 5개 지표(100kW 이상 비중, 충전소당 충전기, 유형 구성, 운영기관 집중도 HHI, 삭제 표시 비중), 두 지역 비교, CSV 내보내기, A4 3쪽 PDF 보고서 |
| 지도 | 카카오맵 위에 충전소 10만 곳을 표시. 줌 11~15에서는 서버가 화면 안의 **모든** 충전소를 격자로 집계해 묶음을 그림. 캔버스 한 장으로 그려 가볍게 동작 |
| 데이터 품질 | 원본 좌표가 의심되는 충전소 644곳(충전기 3,322기, 0.63%)을 찾아 공개. 원본을 고치지 않고 지도 정보창·패널에 안내만 표시 |
| 검증 | 백엔드·배포 테스트 312개, 프론트엔드 160개, 브라우저 회귀 18개 모듈, Python 그래프 수치 대조 50개. 공개 사이트를 실제 브라우저로 점검 |
| 운영 | 512MiB 메모리 한도 안에서 R2 데이터 14개를 SHA-256으로 검증한 뒤 기동. 비밀값은 기동할 때 환경에서 제거. 보안 헤더(CSP 등) 적용 |

## 4. 주요 분석 결과 (공급 측 구성 지표)

| 지표 | 전국 | 가장 높은 지역 | 가장 낮은 지역 |
|---|---|---|---|
| 100kW 이상 충전기 비중 | 8.0% | 경북 14.7% | 대구 4.7% |
| 충전소당 평균 충전기 | 5.22기 | 인천 6.42기 | 제주 2.73기 |
| 운영기관 집중도(HHI, 0~10,000, 운영기관 ID 기준) | 811 | 세종 1,858 | 경북 636 |
| 삭제 표시 비중 | 0.78% | 대구 3.13% | 경기 0.08% |

- 충전기의 88.9%가 AC 완속(02)이고, DC 콤보(04)가 8.3%입니다.
- 운영기관 ID 기준 상위 20개 운영기관이 충전기의 89.4%를 운영합니다(1위 GS차지비 16.8%, 2위 파워큐브 13.1%).
- 이 지표들은 충전기 구성의 차이를 보여 줄 뿐, 충전이 부족한 지역을 뜻하지 않습니다.
- 설치 추이 표에서 누적 설치는 2020년 44,609기에서 2025년 478,802기로 늘었습니다. 이 값은 저장 당시 표 기준이며, 공식 화면은 이후 수정되었습니다.

  - 좌표 품질 분석 보고서와 644곳 목록

## 6. 한계점

- **시점 차이**
  - 전기차 등록(2026-09)과 충전기(2026-10-15)는 기준 시점이 다릅니다.
  - 그래서 부족률·수요·차량당 충전기 같은 결합 지표를 만들지 않았습니다.
- **충전기 상태 해석**
  - 비삭제 표시가 실제로 이용 가능하다는 뜻은 아닙니다.
  - `statUpdDt`는 설치일이 아니라 상태 갱신일시라 설치 시기 분석에 쓰지 않았습니다.
- **설치 추이 자료**
  - 2026년은 부분 연도이고, 집계 마감일이 원본에 없습니다.
  - 공식 화면이 이후 과거 값까지 수정했습니다(누적 최대 1,549기 차이, 사유 미공개).
  - 충전기 API와 모집단이 달라 두 값을 합치지 않습니다.
- **좌표 품질**
  - 원본 좌표 644곳에 의심 근거가 있습니다.
  - 외부 지오코딩으로 확정하지 않았으며, 영향은 주로 지도 위치에 나타납니다.
  - 지역 통계는 지역 코드로 집계하므로 영향이 매우 작습니다.
- **운영기관 집계 기준**
  - 운영기관은 원본의 운영기관 ID(`busiId`) 기준이며, 같은 ID의 서로 다른 운영기관명 표기는 하나로 셉니다.
  - 같은 ID가 반드시 같은 법인이라는 뜻은 아닙니다. 등록 기관과 운영 법인이 다를 수 있는 충전기는 약 1.1%이며, 이를 분리해도 HHI는 최대 6점 이내로 달라집니다.
- **데이터 이용 조건**
  - 충전기 API만 공공누리 제1유형으로 확인되었습니다.
  - 전기차 등록과 설치 추이는 이용 조건이 **미확정**이며, 담당 기관 회신이 필요합니다.
  - 코드 라이선스(LICENSE)도 정하지 않았습니다.
- **운영 환경**
  - Render 무료 플랜이라 한동안 접속이 없으면 절전 상태가 되고, 첫 접속에 시간이 걸립니다.
  - 서버는 1스레드라 요청이 몰리면 잠시 대기합니다.
  - 메모리 그래프는 유료 플랜 전용이라 공개 서버에서 직접 확인하지 못했습니다.
- **검증 범위**
  - Firefox·Safari·실제 모바일 기기는 점검하지 않았습니다.
  - 모바일 정보창이 지도를 많이 가리는 문제가 남아 있습니다.

## 7. 발표에서 강조할 점

1. "부족률"을 계산하지 않은 이유: 시점이 다른 자료를 섞으면 결론이 왜곡되기 때문입니다.
2. 지도가 화면 안 **모든** 충전소를 반영하도록 서버 격자 집계를 도입한 과정
3. 데이터 품질을 숨기지 않고 공개한 점: 좌표 의심 644곳과 설치 추이 수정 기록
4. 테스트와 실제 배포 점검으로 수치 일치를 확인한 방법
