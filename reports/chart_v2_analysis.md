# CHARGE GAP Python 보고서 그래프 v2

기존 PNG 10개와 별개인 신규 200dpi PNG 10개. 9개 서로 다른 복합 그래프 형식(도넛 2회).
충전기 그래프는 기본적으로 비삭제 N 523,312기를 사용한다. API의 기본 deletion=all과 구별한다.
전기차 등록 2025-12와 충전기 조회 2026-10-15는 서로 다른 시점이다. 부족률·인과관계는 계산하지 않는다.

## 1. v2_01_ev_top10.png

- 분석 목적: 지역별 전기차 규모 비교
- 사용 변수: region_name_2025, ev_registration_count
- 종류·선택 이유: 가로 막대 — 긴 지역명을 읽고 순위를 비교하기 쉽다.
- 실제 분석 결과: 경기 207,075대로 전국의 23.03%.
- 출처·기준일: 2025년 12월 자동차 등록자료 · 순수 전기차 · 원래 17개 시도
- 해석 주의: 2025년 등록 규모이며 충전기 부족률을 계산하지 않는다.

## 2. v2_02_vehicle_donut.png

- 분석 목적: 차종 구성 파악
- 사용 변수: ev_passenger_count, ev_bus_count, ev_truck_count, ev_special_count
- 종류·선택 이유: 도넛 — 전체 대비 차종별 비중을 표시한다.
- 실제 분석 결과: 승용 713,835대 (79.39%), 화물 169,744대.
- 출처·기준일: 2025년 12월 자동차 등록자료 · 순수 전기차 · 원래 17개 시도
- 해석 주의: 등록 대수 비율이며 실제 운행량이나 충전 수요 비율이 아니다.

## 3. v2_03_commercial_percent.png

- 분석 목적: 용도별 구성 비교
- 사용 변수: ev_commercial_count, ev_noncommercial_count
- 종류·선택 이유: 100% 누적 가로 막대 — 절대 규모의 영향을 분리하여 지역 내 구성비를 비교한다.
- 실제 분석 결과: 전국 사업용 168,792대 (18.77%). 사업용 비율 최대 인천 40.11%.
- 출처·기준일: 2025년 12월 자동차 등록자료 · 순수 전기차 · 원래 17개 시도
- 해석 주의: 사업용 여부만으로 실제 주행거리 또는 충전 수요를 추정하지 않는다.

## 4. v2_04_stations_chargers_regression.png

- 분석 목적: 지역 규모의 연관성 탐색
- 사용 변수: station_count, charger_count
- 종류·선택 이유: 산점도·회귀선 — 두 수치 변수의 관계와 지역별 편차를 보여준다.
- 실제 분석 결과: 16개 지역 Pearson r=0.98629, R²=0.97278, 회귀 기울기 6.29330. 전국 비삭제 충전소 100,590곳·충전기 523,312기.
- 출처·기준일: 한국환경공단 getChargerInfo · 2026-10-15 04:16–04:19 KST 조회
- 해석 주의: 비삭제 표시(N)만 집계 · 실제 이용 가능 상태를 뜻하지 않음 · 현재 16개 지역 유지 · 상관관계는 인과관계가 아님
