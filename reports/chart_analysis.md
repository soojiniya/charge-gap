# CHARGE GAP 그래프별 분석

Python / Pandas / NumPy / Matplotlib / Seaborn을 사용했습니다. 모든 그래프는 정제 CSV를 사용하며 200dpi PNG입니다. 한글은 Windows 맑은 고딕으로 렌더링했습니다.

## 기준 시점과 분모

- 그래프 1~3: 2025년 12월 순수 전기차 등록 899,101대, 원래 17개 시도.
- 그래프 4~8·10: 2026-10-15 API 조회. 전체 527,433기 / 비삭제 523,312기 / 삭제 표시 4,121기.
- 그래프 4·8은 삭제 표시를 색으로 분리, 6·7·10은 비삭제 모집단을 사용합니다.
- 그래프 5: 고유 충전소 101,091곳. 비삭제 충전기를 가진 곳과 삭제 표시 충전기만 있는 곳을 구분합니다.
- 그래프 9: 별도 연도 Excel 통계의 정규화 CSV. 2026년은 부분 연도이며 정확한 마감일 미기재입니다.
- 비삭제 표시는 실제 이용 가능 상태가 아닙니다. statUpdDt는 설치일이 아닙니다. 서로 다른 시점의 등록 대수와 충전기 수를 나누어 부족률을 만들지 않았습니다.

## 그래프 종류 수

기본 계열은 6종(막대·원형·산점도·히스토그램·선·히트맵)입니다. 가로/세로/누적 막대, 도넛/파이를 별도 표현으로 세면 9종입니다. 가로 막대가 1번·8번에 사용되어 총 10개입니다.

## 1. 01_ev_registration_top10.png

- 분석 목적: 지역별 전기차 등록 규모 비교
- 사용한 데이터: ev_registration_by_region_2025.csv
- 기준일/기간: 2025년 12월
- 그래프 종류: 가로 막대
- 선택 이유: 긴 지역 이름과 순위를 읽기 쉽고 0 기준으로 크기를 비교할 수 있습니다.
- 주요 결과: 경기 207,075대가 전국의 23.03%로 가장 많습니다. TOP 10 합계는 744,793대입니다.
- 해석 주의: 2025-12 등록 재고이며 2026년 충전기 수와 같은 시점의 공급 적정성을 뜻하지 않습니다.

- 분석 목적: 전기차 차종 구성 파악
- 사용한 데이터: ev_registration_by_region_2025.csv
- 기준일/기간: 2025년 12월
- 그래프 종류: 도넛 차트
- 선택 이유: 전국 합계 안에서 4개 차종의 비중을 보여 주고 가운데 합계를 표시합니다.
- 주요 결과: 승용 713,835대 (79.39%); 승합 14,779대 (1.64%); 화물 169,744대 (18.88%); 특수 743대 (0.08%).
- 해석 주의: 차종과 충전기 커넥터 유형은 다른 개념입니다. 아주 작은 특수차 비중은 범례의 수치로 확인합니다.

## 3. 03_ev_commercial_stacked.png

- 분석 목적: 지역별 사업용·비사업용 구성과 규모 비교

- 기준일/기간: 2025년 12월
- 그래프 종류: 누적 막대
- 선택 이유: 전체 규모와 두 용도 집단의 기여를 동시에 보여 줍니다.

- 주요 결과: 경기 155,001기(비삭제 154,877기), 서울 76,202기(비삭제 75,506기) 순입니다. 전남광주통합특별시는 32,913기입니다.

## 5. 05_station_location_scatter.png

- 분석 목적: 전국 충전소의 지리적 분포 확인
- 사용한 데이터: charger_info_clean.csv; statId별 대표 좌표
- 기준일/기간: 2026년 10월 15일 04:16–04:19 KST
- 그래프 종류: 경위도 산점도 지도
- 선택 이유: 고유 충전소의 실제 경위도 위치를 직접 보여 주며 충전기 다수인 곳의 중복 표시를 줄입니다.
- 주요 결과: 유효 좌표를 가진 고유 충전소 101,091곳을 표시했습니다. 비삭제 충전기가 있는 곳은 100,590곳, 삭제 표시 충전기만 있는 곳은 501곳입니다.
- 해석 주의: 행정경계 지도·접근성 분석이 아닙니다. 서로 다른 좌표 쌍이 있는 statId 9개는 비삭제 행 우선 첫 유효 좌표로 대표했습니다. 비삭제 표시는 이용 가능을 뜻하지 않습니다.

## 6. 06_charger_type_pie.png

- 분석 목적: 공식 충전기 커넥터 유형별 비중 확인
- 사용한 데이터: charger_type_summary.csv; 공식 유형 정의
- 기준일/기간: 2026년 10월 15일 04:16–04:19 KST
- 그래프 종류: 파이 차트
- 선택 이유: 합계가 정해진 비삭제 충전기 모집단의 유형 비중을 표시하며 작은 조각은 범례에 정확한 수치를 적습니다.
- 주요 결과: AC완속(02)은 465,025기로 비삭제의 88.86%입니다. DC콤보2 버스전용(11)은 5,584기입니다.
- 해석 주의: 08은 DC콤보(완속)이며 11은 버스전용입니다. 커넥터 유형만으로 급속/완속을 재분류하지 않았습니다. 09 NACS는 이번 조회에 0건이라 조각을 만들지 않았습니다.

## 7. 07_charger_output_histogram.png

- 분석 목적: 개별 충전기의 정격 출력 분포 확인
- 사용한 데이터: charger_info_clean.csv output; charger_output_summary.csv로 구간 검산
- 기준일/기간: 2026년 10월 15일 04:16–04:19 KST
- 그래프 종류: 히스토그램
- 선택 이유: 연속 수치인 출력 분포를 고정 폭 구간에 집계합니다. 드문 고출력 구간도 보이도록 로그 세로축을 사용했습니다.
- 주요 결과: 유효 양수 출력 523,143기, 결측 169기입니다. 중앙값 7kW, 최빈값 7kW(402,997기), 95백분위 100kW, 범위 3~400kW입니다.
- 해석 주의: 로그 눈금의 막대 높이 차이는 선형 대수 차이가 아닙니다. 정격 출력은 실제 충전 속도·동시 공급전력·이용량이 아닙니다.

- 분석 목적: 운영기관별 API 등록 충전기 규모 비교
- 사용한 데이터: charger_info_clean.csv; charger_operator_summary.csv의 공백 정리 후 건수 대조
- 기준일/기간: 2026년 10월 15일 04:16–04:19 KST
- 그래프 종류: 가로 막대
- 선택 이유: 기관명이 길고 순위 비교가 필요하여 가로 막대를 사용했습니다.
- 주요 결과: GS차지비 [PI]는 전체 83,138기, 비삭제 83,132기입니다. 정제된 ID·명칭 조합 342개 중 상위 10개를 표시했습니다.
- 해석 주의: PW의 파워큐브와 파워큐브코리아 등 표기 변형을 임의 합치지 않았습니다. 충전소 고유 수는 운영기관 간 단순 합산하지 않습니다.

## 9. 09_annual_charger_installation_trend.png

- 분석 목적: 원본 통계의 연간 설치량과 누적 변화 확인
- 사용한 데이터: charger_installation_trend.csv
- 기준일/기간: 2011~2026년 연도 통계; 2026 부분 연도; 파일명 날짜 2026-10-15
- 그래프 종류: 선 그래프
- 선택 이유: 시간의 순서와 변화 흐름을 표현하고 연간·누적을 같은 단위의 별도 선으로 구분합니다.
- 주요 결과: 연간 설치 통계 최고는 2023년 111,981기입니다. 2025년 누적 478,802기, 2026년 표기 누적 540,210기이며 2026년 연간 칸의 값은 61,408기입니다.
- 해석 주의: 2026년은 부분 연도이고 정확한 마감일·삭제 처리·집계 범위는 미확인입니다. 2025년 12월 API 재고를 복원하거나 현재 API 총수와 동일시하지 않습니다.

## 10. 10_regional_output_heatmap.png

- 분석 목적: 지역별 충전 출력 구성비 비교
- 사용한 데이터: charger_region_summary.csv; charger_info_clean.csv로 16개 지역 재검산
- 기준일/기간: 2026년 10월 15일 04:16–04:19 KST
- 그래프 종류: 히트맵
- 선택 이유: 지역별 총규모 차이를 분리하기 위해 행 기준 비율을 색으로, 실제 건수를 주석으로 함께 보여 줍니다.
- 주요 결과: 비삭제 중 30kW 미만 양수 출력은 465,877기(89.02%), 200kW 이상은 12,587기(2.41%), 출력 미상은 169기입니다.
- 해석 주의: 색은 지역 내 비율이므로 전국 대수 순위가 아닙니다. 출력 구간은 정책상 속도 분류를 자동 대체하지 않습니다. 전남광주통합특별시를 분할하지 않았습니다.
