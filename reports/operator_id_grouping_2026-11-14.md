# 운영기관 집계 기준: 운영기관 ID(busiId) (2026-11-14)

- 적용 범위: `/api/operators`, 지역 격차의 운영기관 집중도(HHI), 두 지역 비교의 상위 운영기관, 웹 트리맵(그래프 10), Python PY10, 지역 격차 CSV·PDF 보고서
- 기준 상수: `backend/chargegap_api/data.py`의 `OPERATOR_KEY = 'busiId'`
- 원본: 원본 CSV, R2, `data-manifest.json`은 바꾸지 않았습니다. 원본에 이미 있는 기관명 열 `bnm`을 표시 이름으로 읽기만 합니다.

## 1. 기준

- **운영기관 = 원본의 운영기관 ID(`busiId`)**
  - 공공데이터포털 getChargerInfo 명세에서 `busiId`는 "기관ID", `busiNm`은 "운영기관명"입니다.
  - 프로젝트가 처음 활용가이드를 검토한 기록(`reports/dataset_analysis.md`)에도 "busiId는 기관 ID, busiNm은 운영기관명, bnm은 기관명"으로 적혀 있습니다.
- **표시 이름 = 원본 기관명(`bnm`)**
  - 2026-10-15 스냅샷에서 ID 144개와 기관명 144개가 1:1로 대응합니다.
  - 그래도 대비해 코드는 ID별로 가장 많이 쓰인 기관명을 고릅니다.
- **운영기관명(`busiNm`) 표기는 합치지 않고 `name_variants`에 충전기 수와 함께 보존합니다.**
  - ID·운영기관명 조합은 342개입니다.
  - 같은 충전소 안에서도 운영기관명이 다른 경우가 514곳이고, 전화번호나 다른 회사 브랜드명이 들어간 표기도 있습니다.
- **이전 기준 `(busiId, busiNm)` 조합의 문제**
  - 같은 ID의 표기 차이를 서로 다른 운영기관으로 셌습니다(예: 파워큐브 / 파워큐브코리아 / 파워큐브(SP)).
  - 그 결과 집중도가 낮게 계산되었습니다.

## 2. 한계

- **같은 ID가 반드시 같은 법인이라는 뜻은 아닙니다.**
- **확인된 사례**
  - 사명 변경: 한국전자금융 → NICE인프라(2025년 공시)
  - 약칭·영문 표기: 기후부, HUMAX EV 등
  - 사업 분할: 에스트래픽 → 에스에스차저
- **등록 기관과 운영 법인이 다를 수 있는 경우**
  - 위탁 운영이나 소유 기관과 운영사의 분리, 플랫폼명 기재 등입니다.
  - 예: 한국전력공사 ID 아래 한국전기차충전서비스, 서울시 ID 아래 서울에너지공사, 이엘일렉트릭 ID 아래 위브이
  - 규모는 약 6,000기(1.1%)입니다.
- **민감도**
  - 위 충전기를 별도 운영기관으로 떼어 계산하면 전국 HHI는 811에서 810으로 바뀝니다.
  - 지역 HHI 차이는 최대 6점이고, 순위는 인천과 제주(11·12위)만 바뀝니다.
- **확정에 필요한 것**: 한국환경공단 활용가이드의 필드 정의나 기관 회신. 이번에는 확인하지 않았습니다.
