# CHARGE GAP 데이터 통합 계획

## 사실 테이블과 연결 단위

| 테이블 | 단위/기간 | 연결 키 | 사용 원칙 |
|---|---|---|---|
| ev_registration_by_region_2025 | 2025-12, 17개 시도 | reference_month + region_code_2025 | 원래 광주/전남 보존, 순수 전기 연료만 |
| charger_region_summary | 2026-10-15, 16개 시도 | snapshot_date + region_code | API 삭제 포함/비삭제 분리 |
| charger_type_summary | 같은 API 스냅샷, 유형 코드 | snapshot_date + charger_type_code | 공식 01~11 정의, 출력과 구분 |
| charger_operator_summary | 같은 API 스냅샷, 기관 ID·운영기관명 조합 | snapshot_date + busiId + busiNm | 상호명 변형을 임의 병합하지 않음 |
| charger_output_summary | 같은 API 스냅샷, output 원문 | snapshot_date + output_raw | 0 이하·비수치·결측 보존 |
| charger_region_output_excel | 지역 Excel의 16개 시도 | region_code + source_file | 파일명 날짜와 실제 측정일 구분 |
| charger_installation_trend | 2011~2026년 전국 통계 | year + source_file | 2026 미완결, 정확한 마감일 미확인 |
| region_comparison_2025_registration_2026_chargers | 명시적으로 서로 다른 두 시점 | comparison_region_code | 비교용 16개 권역만, 동시점 지표 생성 금지 |

등록과 충전기 자료는 단일 날짜 컬럼을 공유하는 한 테이블로 합치지 않습니다. 기간이 다른 두 사실 테이블을 보존하고 비교용 테이블은 기간 컬럼 두 개와 same_period_ratio_allowed=false를 유지합니다. 설치 통계도 API 스냅샷에 누적 추가하거나 차감하지 않습니다. 등록자료의 전국 합계·소계와 지역 상세를 동시에 더하지 않습니다.

## 행정구역

등록자료 17개 시도 코드는 11,26,27,28,29,30,31,36,41,51,43,44,52,46,47,48,50입니다. API는 12가 광주/전남을 대체한 16개 기준입니다. 현행 공식 코드표 및 2026.7.1 변경 공지를 확인했습니다. 과거 광주·전남을 합산한 비교용 집합은 별도로 만들되 원본 17개를 변경하지 않습니다. 현재 12 데이터를 주소나 좌표 비율로 광주·전남에 분할하지 않습니다. 2025년 당시 현재 지역과의 관계를 인구/면적 비율로 추정하지 않습니다.

## 현재 계산할 수 있는 지표

- 2025-12의 시도별 순수 전기차 등록 대수, 전국 비중, 차종별·사업/비사업용 구성.
- 2026-10-15 API의 지역별 충전기/고유 충전소 수, 공식 유형 구성, 운영기관 구성, 양수 output의 분포.
- 같은 스냅샷 내의 삭제/비삭제 비중, 출력 구간 비중. 비삭제가 현재 사용 가능을 뜻하지 않음.
- 지역 Excel 자체의 출력 구간 구성, 연도 Excel 자체의 설치량·누적값 및 내부 누적 검산.
- 별도 비교 권역에서 서로 다른 시점의 등록·충전기 수를 나란히 열람. 차량당 충전기 수나 부족률로 명명하지 않음.

## 그래프 10개 구성 가능 여부

구성 가능합니다. 이 단계에서 그래프는 생성하지 않았습니다. 다음 10개는 지표·시점을 분리한 설계입니다.

| 번호 | 그래프 구성 | 자료/필드 | 현재 가능 여부·주의 |
|---|---|---|---|
| 1 | 17개 시도 전기차 등록 순위 | 등록 CSV, ev_registration_count | 가능, 2025-12 고정 |
| 2 | 전기차 차종별 구성 | 등록 CSV, passenger/bus/truck/special | 가능, 2025-12 동일 시점 |
| 3 | 전기차 사업/비사업용 구성 | 등록 CSV, commercial/noncommercial | 가능, 2025-12 동일 시점 |
| 4 | 지역별 충전기·충전소 비교 | 지역 요약, charger/station count | 가능, 단위와 삭제 포함 여부 구분 |
| 5 | 지역별 비삭제/삭제 표시 구성 | 지역 요약 count_not_deleted/count_deleted | 가능, 실제 운영 가능률 아님 |
| 6 | 공식 커넥터 유형별 충전기 구성 | 유형 요약 공식 정의 | 가능, NACS 타입만으로 속도 추정 금지 |
| 7 | 출력 값·구간별 충전기 분포 | output 요약, 지역 요약 | 가능, 무효 값 별도·분석 구간 명시 |
| 8 | 운영기관별 충전기 비중 | 운영기관 요약 | 가능, (busiId,busiNm) 조합 유지 |

두 시점 등록-충전기 산점도는 보조 탐색용으로만 허용할 수 있으며 같은 시점의 공급 적정성으로 해석하지 않습니다. 현재 자료로 2025년 부족률, 2026년 차량당 충전기 수, 머신러닝 타깃을 만들지 않습니다.

## 향후 구현 시 검증

원본 식별자는 문자열, 집계값은 정수로 읽습니다. 각 화면에 기준월/스냅샷 시각/지역 체계/삭제 포함 기준을 표시합니다. 유형·운영기관·출력으로 나눈 고유 충전소 수는 서로 겹칠 수 있어 단순 합산하지 않습니다. 정책상 급속 구분이 필요하면 출력 구간과 공식 커넥터 정의를 별도 차원으로 유지하고 기준을 확인합니다. statUpdDt는 상태 갱신일시이며 설치일로 사용하지 않습니다. 원본/기존 정제 파일은 보존하고 향후 갱신은 새 스냅샷으로 추가합니다.
