# 데이터 출처·공개 이용 조건 확인 기록

최초 확인일: 2026-10-19. 재확인일: 2026-11-05(공개자료 페이지의 제1유형 안내를 사용자가 직접 확인하고 공식 검색 색인으로 대조; 로그인·다운로드·문의 없음). 출처 확인과 개별 자료의 공개 이용 허락 확인을 구분한다. 원본 Excel·CSV·PNG·R2 파일은 이 확인을 위해 변경하지 않았다. 이 문서는 코드나 데이터 전체에 라이선스를 부여하지 않는다.

## 화면·API 출처 표기 원칙 (2026-11-05)

출처는 제공기관·작성기관·자료명·자료 기준·수집 시점(파일 저장일 또는 조회 시각)·이용 조건을 구분해 표시한다. 같은 값을 `backend/chargegap_api/data.py`의 `EV_SOURCE`·`API_SOURCE`·`GROWTH_SOURCE`와 `frontend/src/analysis/dataSources.ts`에 두고, `frontend/tests/data-sources.test.cjs`가 두 곳이 같은지 검사한다. 충전기 API의 제1유형은 공공데이터포털에서 확인했다(`license_confirmed: true`). 무공해차 통합누리집 **공개자료 목록**의 제1유형 안내도 확인했지만, 별도 데이터·통계 화면의 설치 추이 Excel에 적용되는지는 미확인으로 둔다.

| 전기차 등록 | 국토교통부 통계누리 · 국토교통부 (자동차등록현황보고) | 2026년 9월 말 등록 기준 | 파일 저장 2026-10-20 | 확인 중 (통계누리 저작권보호정책에 따라 출처 표시) |

"파일 저장"은 사용자 PC에 원본 파일이 저장된 시각이며 공식 다운로드 기록이 아니다.

## EV 등록 통계

로컬 원본은 `2026년_09월_자동차_등록자료_통계.xlsx`, 시트는 `10.연료별_등록현황`이다. 정제 CSV `ev_registration_by_region_2026_09.csv`의 16개 지역 × 7개 값(112개)이 원본과 일치하고 전국 합계는 1,191,873대다(2026-11-04 재확인). 이전 원본 `2025년_12월_자동차_등록자료_통계.xlsx`(899,101대, 17개 시도)는 기록으로 보존하며, 보고서 PNG 1~3번이 이 자료로 그려져 있다.

대응 공식 통계는 국토교통부 **자동차등록현황보고**(승인번호 제116015호)다. [공식 통계·첨부 목록](https://stat.molit.go.kr/portal/cate/statMetaView.do?hFormId=1244&hRsId=58)에 `2026년 09월 자동차 등록자료 통계.xlsx`가 있음을 2026-11-04에 확인했다. 이 페이지에는 공공누리 표시가 없었다.

[통계누리 저작권보호정책](https://stat.molit.go.kr/portal/info/protect.do)은 통계정보를 "자유롭게 사용, 재사용 및 재배포"할 수 있다고 안내하면서, 공공누리 표시가 부착된 저작물인지 확인한 뒤 이용하고 출처에 통계 데이터베이스 명칭과 작성기관명을 반드시 포함하라고 한다. 제3자 권리 등의 예외도 있다. **해당 첨부의 공공누리 표시를 확인하지 못했으므로 일반 정책만으로 최종 공개 허용을 단정하지 않는다.**

화면 출처 표기:

> 국토교통부 통계누리 · 작성기관 국토교통부 · 「2026년 09월 자동차 등록자료 통계」 10.연료별_등록현황 (자동차등록현황보고) · 자료 기준 2026년 9월 말 등록 기준 · 파일 저장 2026-10-20 · 이용 조건 확인 중 (통계누리 저작권보호정책에 따라 출처 표시)

## 충전기 설치 추이

로컬 원본은 `충전기 설치 성장 추세_2026-10-15.xlsx`, 시트 `충전기 설치 성장 추세`, A1:C17이다. 파생 CSV는 2011~2026의 16개 연도이며 2026년은 부분 연도다. 원본과 CSV의 연간·누적 32개 값이 일치한다(2026-11-04 재확인).

[무공해차 통합누리집 데이터·통계](https://ev.or.kr/nportal/stats/statsDashboard.do)에 같은 제목의 표와 Excel 다운로드가 있다. 2026-10-19 확인 당시 공식 화면(갱신 표시 2026-09-30)의 32개 값은 로컬 CSV와 일치했다.

**공식 수치 수정 (2026-11-04 확인):** 공식 화면은 2026-10-31 갱신에서 2011년을 제외한 모든 연도의 값이 달라졌다. 예: 2025년 연간 89,805 → 89,429기, 누적 478,802 → 477,300기, 2026년(부분) 누적 540,210 → 541,759기. 누적 차이는 최대 1,549기다. **수정 사유는 공식적으로 확인되지 않았다.** 프로젝트는 2026-10-15에 저장한 당시 표를 그대로 유지하며(충전기 API 조회일과 같은 날짜), 화면과 API(`revision_note`)에 "당시 자료이며 현재 공식 최신값이 아님"을 표시한다. 기존 `measurement_cutoff_date` 결측과 부분 연도 처리를 유지한다.

[공개자료 목록](https://ev.or.kr/nportal/infoGarden/initPublicdataAction.do)은 "모든 데이터셋"에 공공누리 제1유형과 "무공해차 통합누리집" 출처 표기를 안내한다. 그러나 이 목록(10건)과 데이터·통계 화면의 설치 추이 Excel이 같은 자료라고 확인되지 않았고, 데이터·통계 화면에는 이용 조건 문구가 없다. [회원 약관](https://ev.or.kr/nportal/member/initMemberJoinAction.do)에는 별도의 재배포 제한 문구도 있다. 따라서 목록의 허락을 이 표로 확대 적용하지 않는다.

화면 출처 표기:

> 무공해차 통합누리집 · 작성기관 원본 미기재 · 데이터·통계 「충전기 설치 성장 추세」 2011–2026 (2026년 부분 연도) · 자료 기준 집계 마감일 원본 미기재, 당시 공식 화면 갱신 표시 2026-09-30 · 파일 저장 2026-10-15 · 이용 조건 확인 중

## 공개 전 판정

| 대상 | 확인된 근거 | 남은 확인 |
| --- | --- | --- |
| 한국환경공단 API | 공식 이용허락범위 제1유형 | 없음 (출처 표시 유지) |
| EV 등록 Excel (2026-09) | 공식 첨부 목록·일반 재이용 정책 | 해당 첨부의 공공누리 표시 또는 통계누리(044-201-4834)의 적용 안내 |
| 설치 추이 Excel | 공식 대응 표 | 해당 표/Excel에 적용되는 이용 조건 (무공해차 통합누리집 1661-0970 또는 데이터 요청 게시판) |
| PNG·파생 집계 | 프로젝트 제작 결과물 | 입력 자료 조건도 확인 |

사용자는 최초 URL을 정확히 보유하지 않는다고 확인했다. 비공개 R2나 Private GitHub는 공개 웹/API 표시·재배포 권한을 대신하지 않는다. CSV 다운로드 라우트가 없어도 수치·PNG가 제공된다. 필요한 증거는 개별 공공누리 표시나 담당기관의 재사용 안내다. 사용자 동의만으로 제3자 권리가 확정되었다고 처리하지 않는다.
