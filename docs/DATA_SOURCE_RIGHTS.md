# 데이터 출처·공개 이용 조건 확인 기록

확인일: 2026-10-19. 출처 확인과 개별 자료의 공개 이용 허락 확인을 구분한다. 원본 Excel·CSV·그래프·API·UI는 이 확인을 위해 변경하지 않았다. 이 문서는 코드나 데이터 전체에 라이선스를 부여하지 않는다.

## EV 등록 통계

로컬 원본은 `2025년_12월_자동차_등록자료_통계.xlsx`, 시트는 `10.연료별_등록현황`이다. 기존 정제 CSV의 전기 연료·소계·용도 계 집계는 2025-12 총 899,101대다.

대응 공식 통계는 국토교통부 **자동차등록현황보고**(승인번호 116015)다. [공식 통계·첨부 목록](https://stat.molit.go.kr/portal/cate/statMetaView.do?hFormId=1244&hRsId=58)에서 `2025년 12월 자동차 등록자료 통계.xlsx`와 JavaScript 다운로드 항목을 실제 확인했다. 이 페이지에서 해당 월 파일을 선택할 수 있다.

[통계누리 저작권보호정책](https://stat.molit.go.kr/portal/info/protect.do)은 재사용·재배포를 안내하면서 개별 공공누리 표시 확인과 구체적인 출처 표시를 요구한다. 제3자 권리 등의 예외도 있다. 이번에 해당 첨부의 공공누리 표시, 최초 다운로드 이력, 로컬 원본과 공식 첨부의 바이트 동일성은 확보하지 못했다. **일반 정책만으로 이 로컬 파일의 최종 공개 허용을 단정하지 않는다.**

조건 확인 후의 출처 표시 예:

> 국토교통부 통계누리(국토교통부, 자동차등록현황보고), 2025년 12월 자동차 등록자료 통계, 10.연료별_등록현황. CHARGE GAP 전기차 항목 정제·지역 집계. 공식 출처 확인: 2026-10-19.

확인일은 최초 다운로드 일자가 아니다. 알 수 없는 날짜를 만들지 않으며 공식 링크·기준월·분류와 의미를 유지한다.

## 충전기 설치 추이

로컬 원본은 `충전기 설치 성장 추세_2026-10-15.xlsx`, 시트 `충전기 설치 성장 추세`, A1:C17이다. 파생 CSV는 2011~2026의 16개 연도이며 2026년은 부분 연도다.

[무공해차 통합누리집 데이터·통계](https://ev.or.kr/nportal/stats/statsDashboard.do)의 공식 검색 인덱스에서 같은 제목의 표를 찾았고 연간·누적 32개 값이 로컬 CSV와 일치했다. 공식 표시의 갱신일은 2026-09-30이며, 이는 로컬 파일명 날짜 2026-10-15와 구분한다. 해당 표시를 로컬 Excel의 정확한 마감일로 소급 확정하지 않는다. 기존 `measurement_cutoff_date` 결측과 부분 연도 처리를 유지했다.

[공개자료 목록](https://ev.or.kr/nportal/infoGarden/initPublicdataAction.do)은 그 목록의 자료에 제1유형·출처 표시를 안내한다. 그러나 그 목록의 충전기 활용 상세자료와 설치 추이 Excel이 동일한 자료라고 확인되지는 않았다. [회원 약관](https://ev.or.kr/nportal/member/initMemberJoinAction.do)에는 별도의 재배포 제한 문구도 있다. 따라서 목록의 허락을 모든 대시보드 표로 확대 적용하지 않는다.

**미확정:** 이 설치 추이 표/Excel에 직접 적용되는 공공누리 표시 또는 제공기관 이용 안내, 최초 다운로드 이력·바이트 동일성. 자동 HTTP 본문은 JavaScript 보호 형태라 검색 인덱스의 표와 이용 조건을 같은 응답에서 직접 대조하지 못했다. 보호를 우회하지 않았다.

조건 확보 후의 출처 표시 예:

> 무공해차 통합누리집, 데이터·통계 — 충전기 설치 성장 추세(2011~2026, 2026년 부분 연도), CHARGE GAP 집계·시각화. 원본 파일명 날짜 2026-10-15, 정확한 집계 마감일은 원본 미기재. 공식 대응 표 확인: 2026-10-19.

이 예시는 사용 허가를 의미하지 않는다. 작성기관·마감일이 확정되면 그 근거에 맞춰 표기한다.

## 한국환경공단 API

[공공데이터포털 전기자동차 충전소 정보](https://www.data.go.kr/data/15076352/openapi.do)의 HTML에서 공공저작물 출처표시 제1유형을 재확인했다. 표기 예: “한국환경공단 전기자동차 충전소 정보(getChargerInfo), 2026-10-15 조회, CHARGE GAP 정제·집계”. 수집 인증키는 배포에 필요하지 않다.

## 공개 전 판정

| 대상 | 확인된 근거 | 남은 확인 |
| --- | --- | --- |
| 한국환경공단 API | 공식 이용허락범위 제1유형 | 실제 공개 화면/API/PNG의 출처 표시 준수 |
| EV 등록 Excel | 공식 첨부 목록·일반 재이용 정책 | 개별 공공누리 표시·로컬 원본 연결 증빙 |
| 설치 추이 Excel | 공식 대응 표·32개 수치 일치 | 해당 표/Excel에 적용되는 직접적인 공개 조건 |
| PNG·파생 집계 | 프로젝트 제작 결과물 | 입력 자료 조건도 확인 |

사용자는 최초 URL을 정확히 보유하지 않는다고 확인했다. 비공개 R2나 Private GitHub는 공개 웹/API 표시·재배포 권한을 대신하지 않는다. CSV 다운로드 라우트가 없어도 수치·PNG가 제공된다. 미확정 상태에서 공개하면 출처 누락·이용 조건 위반·제공기관 오표기 문제가 생길 수 있으므로 **공개 배포 전 확인 필요**를 유지한다. 필요한 증거는 개별 공공누리 표시나 담당기관의 재사용 안내다. 사용자 동의만으로 제3자 권리가 확정되었다고 처리하지 않는다.
