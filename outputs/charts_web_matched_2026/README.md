# 웹사이트 그래프 1~10 Python 구현 (흰 배경)

현재 CHARGE GAP 웹사이트의 그래프 1~10을 기준으로 삼았습니다. 같은 원본 CSV를 Python(pandas)으로 다시 집계했고, Matplotlib·Seaborn으로 새로 그렸습니다. 웹 화면을 캡처하거나 색만 바꾼 그래프가 아닙니다.

- 생성: `python scripts/create_web_matched_charts_2026.py --data-dir <data/processed>`
  - 같은 CSV로 다시 실행하면 같은 PNG가 나옵니다(SHA-256 동일 확인).
- API 대조: `python scripts/verify_web_matched_charts_2026.py --api http://127.0.0.1:5000`
  - 웹 코드의 계산 규칙을 그대로 옮겨 API 응답에서 다시 계산한 값과 비교합니다.
- 데이터 기준
  - 전기차: 2026년 9월 등록, 1,191,873대, 16개 시도(전남광주 통합)
  - 충전기: 2026-10-15 04:16–04:19 KST 조회, 전체 527,433기(삭제 표시 4,121기 포함). 웹 기본 필터와 같습니다.
  - 설치 추이: 2011–2026년 통계(2026년은 부분 연도)

## 1. 웹사이트 실제 구현과 요청 목록 대조

요청한 10개 그래프의 종류와 목적은 웹 코드(`frontend/src/features/ChartCards.tsx`, `frontend/src/charts/*.tsx`)와 모두 일치합니다. 다만 웹에만 있는 기본 동작이 몇 가지 있어 그대로 따랐습니다.

| 번호 | 웹 카드 제목 | 웹 그래프 종류 | 웹 기본 동작 중 반영한 점 |
|---|---|---|---|
| 01 | 지역별 전기차 등록 대수 | 가로 막대 | 16개 시도 전체, 내림차순, 1위 강조, 막대 끝에 정수 표시 |
| 02 | 차종별 등록 구성 (전국) | 가로 롤리팝 | 등록 대수 순(승용·화물·승합·특수), 점 오른쪽에 대수·구성비(소수 1자리) |
| 03 | 지역별 사업용·비사업용 전기차 구성 | 100% 누적 가로 막대 | 기본 보기는 "비율"(대수 보기는 미반영). 사업용 비율 내림차순, 같으면 지역 코드 순 |
| 04 | 지역별 충전소 수와 충전기 수의 관계 | 산점도 + 최소제곱 회귀선 | 지역 필터 제외. 회귀선은 y=0 지점부터 최대 x × 1.04까지. 라벨은 충전소 수 상위 2곳과 충전소당 충전기 최대·최소 지역 |
| 05 | 충전소당 충전기 수 분포 (지역별 박스플롯) | 박스플롯 | **삭제 표시 필터가 '전체'일 때 비삭제 표시(N)만 집계.** 중앙값→Q3→평균 내림차순, 로그 가로축. 이상치는 값마다 점 하나, 점 크기 = 그 값을 가진 충전소 수 |
| 06 | 충전기 유형별 구성 | 도넛 | 상위 4개 + 기타 |
| 07 | 충전기 정격 출력 분포 | 히스토그램 + KDE | 로그 x(log10 구간 폭 0.125), **기본 로그 y**, KDE 대역폭 0.125 |
| 08 | 지역별 충전기 출력 구간 구성 | 히트맵 | 6개 구간(미상 포함), 행 기준 %. 색은 열마다 상대값. 10% 이상은 정수, 미만은 소수 1자리. 충전기 수가 많은 지역 순 |
| 09 | 연도별 누적 충전기 설치 추이 | 누적 영역 | 완료 연도는 영역 + 실선, 2025→2026은 점선, 부분 연도 띠. 연간 막대는 별도 카드라 넣지 않음 |
| 10 | 운영기관별 충전기 규모 | 트리맵 | 운영기관 ID 기준 상위 20개 + 기타. 순위별 색 구간(1 / 2·3 / 4–6 / 7–10 / 11–20 / 기타) |

## 2. 그래프별 사용 함수·라이브러리

| 번호 | 실제 사용한 함수 |
|---|---|
| 01 | `seaborn.barplot(orient="h")`, `Axes.text` |
| 02 | `Axes.hlines`, `Axes.scatter`, `Axes.annotate` (Matplotlib), `seaborn.set_theme` |
| 03 | `Axes.barh(left=…)` 2계열 누적 (Matplotlib) |
| 04 | `seaborn.regplot(scatter=False, ci=None)`, `seaborn.scatterplot`, 검증용 `numpy.polyfit` |
| 05 | `seaborn.boxplot(log_scale=True, showmeans=True)`, 이상치는 `Axes.scatter`, 검증용 `Series.quantile(linear)` |
| 06 | `Axes.pie(wedgeprops=width)` (Matplotlib) |
| 07 | `seaborn.histplot(weights, bins, kde=True)` (내부적으로 SciPy `gaussian_kde`, 대역폭 고정), `Axes.set_yscale('log')` |
| 08 | `seaborn.heatmap(annot=…)`, `pandas.crosstab` |
| 09 | `Axes.stackplot`, `Axes.plot`, `Axes.axvspan` (Matplotlib). 곡선은 웹과 같은 monotoneX 보간 |
| 10 | 웹 recharts Treemap의 squarify 배치를 Python으로 옮긴 `recharts_squarify` + `matplotlib.patches.Rectangle` |

트리맵은 처음에 `squarify` 라이브러리로 그렸습니다. 그런데 이 라이브러리는 칸 배치 방식이 웹과 달라서, 웹 recharts의 알고리즘(aspectRatio 1.6, 픽셀 반올림 포함)을 직접 옮겼습니다. 그 결과 웹 화면(1250×380px)의 21개 칸 위치와 크기가 픽셀 단위로 같습니다.

## 3. 데이터 검증 결과

- **API 대조**: 46/46 일치. 자세한 내용은 `verification.md`, `verification.json`에 있습니다.
  - 순서, 대수, 비율 표기, 회귀계수, 박스플롯 통계, 히스토그램 19개 구간, KDE, 히트맵 96칸, 설치 추이, 운영기관 상위 20개를 모두 비교했습니다.
- **실제 화면 대조**: 13/13 일치(`verification_screen.json`). 로컬 웹 화면(기본 필터, 1600px 창)을 Playwright로 열어 카드 글자와 트리맵 칸 위치를 읽어 비교했습니다. 이 화면 대조용 임시 스크립트는 저장소에 넣지 않았습니다.
  - 막대 끝 숫자, 사업용 비율 16개, 회귀식, 박스플롯의 n·중앙값·Q1·Q3, 히트맵 96칸 숫자, 트리맵 칸 배치를 확인했습니다.
- **KDE**: Seaborn KDE와 웹 `weightedKde` 값의 차이는 구간 중앙 기준으로 최대 0.11%입니다(생성 스크립트가 0.5% 이내인지 확인).
- **단위·분모**
  - 01–03은 대(등록), 04–08·10은 기(충전기)·곳(충전소)입니다.
  - 분모는 그래프마다 다릅니다.
    - 02: 전국 등록 합계
    - 03·08: 지역 합계
    - 06·10: 필터와 일치하는 전체 충전기 527,433기
    - 05: 비삭제 표시 충전소 100,590곳
  - 지역은 모두 16개 시도이고, 12번 지역은 '전남광주'로 표시합니다.

## 4. 숫자가 달라 보일 수 있는 이유 (실제 값은 같음)

- **07의 7kW 구간 막대는 406,962기**입니다. 화면 분석 문구의 최빈값은 406,961기(7kW)입니다. 6.49–8.66kW 구간에 6kW 충전기 1기가 함께 들어가기 때문입니다.
- **05의 표본은 100,590곳으로, 다른 충전기 그래프의 전체 527,433기와 기준이 다릅니다.** 웹 기본 필터가 '전체'여도 이 그래프만 비삭제 표시로 집계하기 때문입니다.
- **축 눈금 위치가 다릅니다.** 예를 들어 01의 웹 눈금은 7.5만 간격, Python은 5만 간격입니다. recharts와 Matplotlib의 자동 눈금 규칙 차이이며, 표시값과 축 단위는 같습니다.
- **08의 '미상' 열은 모든 칸이 0.0~0.1%인데도 색 차이가 큽니다.** 웹과 같이 열마다 최소~최대로 상대 색을 칠하기 때문입니다.
- **색과 상호작용**: 색은 다크 테마 대신 흰 배경과 원본 그래프의 색 계열을 썼습니다. 마우스 툴팁, 지역 선택, 보기 전환은 정적 이미지라 넣지 않았습니다.
